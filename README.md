# Focus Timer

A minimal productivity application featuring a Pomodoro countdown timer and a stopwatch for developer study sessions.

Built with **vanilla HTML, CSS, and JavaScript**. Hosted by **Codebreakers** to encourage hands-on open-source contributions.

---

## Getting Started Locally

No installation or build tools needed.

1. Fork and clone this repository:
   ```bash
   git clone [https://github.com/](https://github.com/)<your-username>/cb-focus-timer.git
   cd cb-focus-timer

    Open index.html in your web browser.
